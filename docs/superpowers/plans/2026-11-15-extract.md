# Extract Implementation Plan (Bifröst, step 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `bifrost daemon` that owns people, devices, device tokens, the audit log and the
loopback request pipeline, built from Sleipnir's identity code, with Sleipnir left unchanged.

**Architecture:** A new .NET 10 solution in the Bifröst repository. The code comes from
`Sleipnir.Server` (identity, persistence, security, hosting) and is renamed into Bifröst's words:
users become **people**, a device gains a **kind**. Sleipnir keeps its own copy until step 2, when it
gains the "under Bifröst" mode and drops it. So "Sleipnir alone keeps working throughout" holds by
construction: no Sleipnir file changes in this plan.

**Tech Stack:** .NET 10 (SDK 10.0.402), ASP.NET Core minimal APIs on Kestrel, EF Core 10 + SQLite
with snake_case names, OpenAPI + Scalar, xUnit, `FakeTimeProvider`, CsCheck.

**Spec:** `Bifrost/docs/design.md` (§3, §5, §6.1, §6.4, §11, §12 step 1). Source of the code:
`Sleipnir/src/Sleipnir.Server` and `Sleipnir/tests/Sleipnir.Tests/Server` as of Sleipnir `555838f`
plus the uncommitted "a member cannot shut the daemon down" change.

## Global Constraints

- .NET 10, `global.json` pinning `10.0.402` with `rollForward: latestFeature` (as Heimdall).
- `Directory.Build.props` copied from Heimdall: `Nullable`, `ImplicitUsings`, `TreatWarningsAsErrors`,
  `AnalysisLevel latest-recommended`, `NuGetAudit` with mode `all` and level `low`.
- Packages, versions as Heimdall and Sleipnir use today: `Microsoft.EntityFrameworkCore.Sqlite` 10.0.15,
  `Microsoft.EntityFrameworkCore.Design` 10.0.15, `EFCore.NamingConventions` 10.0.1,
  `Microsoft.AspNetCore.OpenApi` 10.0.14, `Scalar.AspNetCore` 2.19.0, `xunit` 2.9.3,
  `xunit.runner.visualstudio` 4.0.1, `Microsoft.NET.Test.Sdk` 18.11.0,
  `Microsoft.Extensions.TimeProvider.Testing` 10.11.0, `CsCheck` 5.0.1.
- Errors are problem+json with a stable `code` (Sleipnir's `Problem`).
- Heimdall secret rules: D3 (256-bit secrets, stored as SHA-256), D4 (constant-time comparison),
  D5 (one error per failure kind), D7 (never log secrets).
- Time comes from `TimeProvider`, never `DateTime.UtcNow` (replaces Sleipnir's `Func<DateTimeOffset>`).
- Tokens in the `Authorization` header only. No cookies. No CORS headers. `Host` must be
  `localhost`, `127.0.0.1` or `[::1]` (§6.4; LAN names arrive in step 3).
- Loopback HTTP only. Default port `7780` [my call: Sleipnir alone uses 7766], next 19 tried when busy.
- No GPL code. Licence MIT, pending the owner's confirmation (§3 "MIT is suggested").
- Roles are `admin` and `member`, stored lower-case. Device kind is `app` or `browser-fallback`.
- The command is `bifrost`. The data folder is named `bifrost`. Database file `bifrost.db`.
- Bifröst does not reference any Sleipnir assembly. Code is copied, not shared (suite principle 4).

## Review Focus

1. **Names that differ only by case or spaces** (`"Bob"` and `" bob "`): the second is `name_taken`,
   not a second person. Test in Task 4.
2. **A revoked device, or a deleted person's device, on its very next request**: 401, no grace
   period, no cached principal. Test in Task 5.
3. **The last admin demoted or deleted, including two requests at once**: exactly one may win, and
   there is always an admin afterwards. Test in Task 4.
4. **A `Host` header that only looks local** (`localhost.evil.example`, `127.0.0.1.nip.io`): refused
   with `host_not_allowed`, while `localhost:7780` is accepted. Test in Task 5.
5. **A restart after the token file was deleted, or the database file's mode was widened**: the new
   token works, the old one does not, the file is `0600` again. Test in Task 6.
